1. システム基本5要素の整理

5 Core Elements
01

入力 (Input)

Touch & Stylus
  • ・スタイラスペン / タッチ: 描画座標・筆圧ストローク
  • ・5つの感情パラメータ: たのしい/おどろき/せつない/こんらん/しげきてき
  • ・壺の形状選択（vaseShape）、背景テーマ、作者署名サイン
02

処理 (Processing)

Client & Server
  • ・手元タブレット: HTML5 Canvas 上のUVテクスチャリアルタイム展開
  • ・縦型モニター: Three.js による3D壺メッシュ・シェーダー描画
  • ・システム本体 (Cloud Run): Socket.io による低遅延双方向中継
  • ・クラウド処理: 4方向画像キャプチャ合成 & 感情データ解析
03

出力 (Output)

Visual & Cloud
  • ・縦型モニター: 3D回転壺のリアルタイムペイント映像
  • ・手元タブレット: 描画UI、エフェクト反映、完了時手元QR表示
  • ・Instagram: Graph API 経由での4面カルーセル自動投稿
  • ・スマートフォン: 手元QRコード読取で公式Instagramを開き作品閲覧
04

ネットワーク (NW)

LAN / WAN
  • ・会場LAN: 会場用ルーター（電波干渉の少ない 5GHz 帯 Wi-Fi 推奨）
  • ・WebSocket (Socket.io): 描画・感情データの即時ブロードキャスト
  • ・HTTPS REST API: Cloud Run / Firebase / Meta API 通信
05

電源 (Power)

Continuous Supply
  • ・商用 AC 100V: 縦型モニター、駆動用PC、Wi-Fiルーター（常時給電）
  • ・USB-PD 急速給電: 手元タブレット（体験中の電池切れ・減光防止）
  • ・無停電電源 (UPS): 展示の安定稼働と瞬低保護（推奨）
